# NetworkSecure – Secure Enterprise Network Design and Implementation

## Project Overview
NetworkSecure is an individual enterprise network design project developed using Cisco Packet Tracer. The main objective is to design a structured network and implement basic network security features.

## Technologies Used
- Cisco Packet Tracer
- Cisco IOS
- Cisco ASA Firewall
- VLAN
- DHCP
- Inter-VLAN Routing
- Access Control Lists (ACLs)
- NAT
- SSH

## Key Features
- Designed a multi-VLAN network architecture.
- Configured four VLANs: Management, Staff, Guest, and IT.
- Implemented Inter-VLAN Routing.
- Configured DHCP for automatic IP address assignment.
- Applied ACLs to isolate the Guest network.
- Configured Switch Port Security.
- Enabled SSH Version 2 for secure remote access.
- Configured Cisco ASA Firewall and NAT.
- Tested HTTP/HTTPS services and network connectivity.

## VLAN Configuration

| VLAN | Name | Network |
|---|---|---|
| 10 | Management | 192.168.10.0/24 |
| 20 | Staff | 192.168.20.0/24 |
| 30 | Guest | 192.168.30.0/24 |
| 40 | IT | 192.168.40.0/24 |
